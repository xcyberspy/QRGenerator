<h2>🧐 Features</h2>

Here're some of the project's best features:

*   🔲 Generate QR codes from any text or URL.
*   🎨 Customizable QR color via a built-in color picker.
*   📋 Copy the input text to the clipboard with one click.
*   🖼️ Embed a logo in the center of the QR code with validation on image size (max 5000×5000 px).
*   🔢 Character counter (up to 500 characters) with color-coded warnings based on length.

<h2>🛠️ Installation Steps:</h2>

<p>1. Clone the repository:</p>

```
git clone https://github.com/xcyberspy/QRGenerator
```

<p>2. Navigate to the Directory</p>

```
cd QRGenerator
```

<p>3. Install Required Packages</p>

```
pip install customtkinter qrcode[pil] pillow pyperclip validators
```

<p>4. Run the application</p>

```
python "QR Generator.py"
```
